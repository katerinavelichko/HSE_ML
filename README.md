# HSE_ML
## Задания по курсу машинного обучения HSE


### Непараметрический LDA и Local Likelihood Logistic Regression
- Реализация непараметрического LDA с подбором ядер и параметра регуляризации
- Сравнение с регуляризованным LDA из sklearn по времени работы и качеству
- Реализация Local Likelihood Logistic Regression и сравнение с другими методами

### Классификация графов с использованием ядерных методов
- Применение kernel trick для классификации графов с Ridge регрессией и SVM
- Использование библиотеки GraKeL для работы с графами
- Подбор оптимальных ядер для классификации
- Эксперименты с конструированием новых ядер

### Подбор гиперпараметров с Gaussian Process
- Реализация Gaussian Process для подбора гиперпараметров Random Forest/бустинга
- Сравнение с Random Search по скорости и качеству
- Работа с датасетами с большим количеством признаков (>20)
- Эксперименты с критериями подбора точек и ядрами

### Robust PCA 
- Реализация Robust PCA
- Проверка способности Robust PCA отделять фон от движущихся объектов  в видео
- Проверка способности Robust PCA к удалению теней и бликов с изображений лиц


### Методы уменьшения размерности для графов
- Применение методов уменьшения размерности (MDS, t-SNE, UMAP) к графам через ядерные расстояния
- Визуализация 2D эмбеддингов и построение моделей классификации
- Эксперименты с комбинациями ядер и методами уменьшения размерности

### Вероятностные методы уменьшения размерности
- Реализация Probabilistic PCA с использованием PyMC
- Реализация Supervised PCA, Partial Least Squares и CCA
- Сравнение PCA и Supervised PCA 

###  Dynamic Ensembling
- Применение методов динамического ансамблирования из библиотеки DESlib (работа с датасетами HIGGS и Wine Quality)
- Сравнение с индивидуальными моделями по метрикам accuracy и MSE
- Анализ важности фич и предсказаний отдельных моделей

### Кластеризация
- Реализация distance and density based clustering
- Применение к различным датасетам с визуализацией для 2D случаев
- Оценка качества с помощью normalized_mutual_info_score
- Методы определения количества кластеров, применение нестандартных методов

### Нейронные сети для табличных данных
- Исследование компонентов ResNet (batchnorm и residual connection) для табличных данных
- Модификации архитектуры (dropout, активации, нормализация)
- Сравнение с MLP

### Метод TabR
- Применение метода TabR для табличных данных
- Анализ ближайших соседей в скрытом и исходном пространствах
- Характеристика различий между соседями в разных пространствах
